# Проверка сайта

Аргумент (необязательно): путь страницы, например `/about.html`. По умолчанию `/`.

1. Запусти превью `site` (`mcp__Claude_Browser__preview_start` с `name: "site"`) и открой нужный путь.
2. **Мобильная ширина**: `resize_window` с `preset: "mobile"`, перезагрузи страницу, сделай скриншот.
   Проверь через `javascript_tool`, что нет горизонтального скролла:
   `document.documentElement.scrollWidth <= window.innerWidth`.
3. **Десктоп**: `resize_window` с `preset: "desktop"`, скриншот.
4. **Консоль**: `read_console_messages` с `onlyErrors: true` — ошибок быть не должно.
5. **Ресурсы**: `read_network_requests` — нет ответов 404/500 (кроме намеренных).
6. **Доступность** (через `javascript_tool`):
   - ровно один `h1`;
   - у всех `img` есть атрибут `alt`;
   - у `html` есть `lang`;
   - у страницы есть `<title>` и `meta[name=description]`.
7. Проверь тёмную тему: `resize_window` с `colorScheme: "dark"`, скриншот, затем верни `light`.

Итог — короткий список: что в порядке, что сломано (файл и строка), что стоит поправить.
Сам ничего не исправляй, если об этом не просили.
