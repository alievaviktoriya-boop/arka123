Анимация встраивается на сайт, проигрывается **прокруткой** и служит **фоном сайта**.

- **Рилс 1 — сайт Porsche 911.** Полноэкранное видео машины — это и есть фон сайта. В кадре видно ТЗ автора:
  - при заходе первое видео запускается **само, без прокрутки**, и доходит до второй сцены, где появляется первый блок;
  - дальше — **только по прокрутке**: один шаг колеса/свайпа = переход к следующей сцене;
  - содержимое блока появляется **только после того, как видео перехода доиграло**;
  - шапка и счётчик блоков `01 ———` общие для всех сцен;
  - все сцены и переходы описаны в **одном конфиге** — заменить видео = поправить конфиг.
- **Рилс 3 — «Интерактивный экран», Balenciaga.** Модель в полноэкранном видео, смена кадров (лес → дерево → крупный план)
  по прокрутке, тёмная кинематографичная гамма, минимум текста поверх.

**Вывод:** заказчику нравятся сайты, где **весь экран — видео**, которое по прокрутке **переходит от сцены к сцене**
(а не плавно «прокручивается» кадр за кадром), а текстовые блоки проявляются поверх в паузах между переходами.
Это и есть «запускаться при скролинге, выступая фоном сайта».

## Главный принцип: собираем ролик из коротких клипов «от кадра к кадру»

Нейросети держат лицо и помещение только на коротких отрезках (5–8 с). Поэтому:

1. Сначала делаем **ключевые кадры** (картинки) в Gemini: Аркадий + реальные фото зала.
2. Потом каждый клип генерируем в режиме **начальный кадр → конечный кадр** (image-to-video).
3. Конечный кадр клипа N = начальный кадр клипа N+1 → склейка без швов.

Зал на ключевых кадрах берём **с реальных фото заказчика** — бриф запрещает искажать помещение,
а так нейросеть только анимирует то, что уже есть на фото.

Референс лица и костюма для всех кадров: `Генерации/аркадий-рост.png` и `Карточка героя@1x.png`.

## Технические требования к итоговому ролику

- 16:9, 1920×1080 (минимум 1280×720), 24–30 к/с, итог 20–30 с, **без звука**.
- Важное держать в центральной трети кадра: на телефоне видео обрезается до вертикали.
- Склеить клипы по порядку в любом редакторе (CapCut подойдёт), без переходов — стыки и так совпадают.
- Сдать мне один файл `.mp4`. Я перекодирую его так, чтобы каждый кадр был ключевым (через ffmpeg) —
  это нужно для плавного перехода **назад** — и подключу на сайт.
