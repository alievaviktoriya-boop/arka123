## Требования к видео с Аркадием

- Вертикальный и горизонтальный варианты не нужны: один ролик 16:9, 1920×1080 или 1280×720, 8–15 секунд.
- Сюжет по сцене сайта: Аркадий стоит слева → чертит светящуюся арку → в ней проявляется зал →
  камера пролетает сквозь арку в зал → проходит по залу → останавливается у окна с видом на библиотеку.
- Для плавной перемотки прокруткой ролик нужно перекодировать «каждый кадр ключевой» (сделаю сам через ffmpeg).
- Файл положить в `assets/video/arkadiy.mp4` и добавить `data-video` на `.film` в `index.html`.
