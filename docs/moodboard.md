### 1. Belgrade Arbor — след курсора ✅

- Как сделано: поверх видео второй слой (то же видео, искажённое «как сквозь стекло»); курсор открывает его
  мягкой маской-кистью (SVG-маска + `feGaussianBlur`), след тянется и тает. Canvas/WebGL не используется.
- Берём: кисть за курсором поверх нашего видео-фона, но открывает она **голубое свечение портала `#7FD3FF`**
  (как будто Аркадий колдует курсором). Только десктоп (на телефоне нет курсора), учитывать `prefers-reduced-motion`.

### 2. Overworld Audio — логотип ✅

- Как сделано: полноэкранный тёмный фон (глубокий сине-чёрный, на canvas — лёгкое «зерно»), по центру —
  **маленький** светлый словесный знак: `OVERWORLD` 12px, трекинг 0,4em, капс + `AUDIO` 8px приглушённым
  сине-серым `#6E8799`. Под ним линия прогресса 120 × 1px (`scaleX` 0→1, `transition .4s`) и `100%` 9px.
  По загрузке логотип гаснет (fade .4s), появляется кнопка «Enter with sound» с тонкой обводкой — вход по клику.
- Берём:
  - Прелоадер **тёмный** (`--night`), знак АРКА **светлый** (`--paper`), подпись «123 · зал в Минске» —
    мелким капсом с трекингом, приглушённым цветом. Знак небольшой — ощущение дорогой тишины.
  - Тонкая линия прогресса 1px вместо крупной анимации; заполняется **голубым `--portal`**, как будто
    зажигается арка. В конце — арка-окно знака светится и раскрывается в первый кадр видео:
    **ночь → сумерки (вечерний променад) → день (зал)**.
  - Без кнопки «войти со звуком» — у нас видео без звука, переход автоматический.
  - Зерно — по желанию, CSS-шумом (SVG `feTurbulence` в `background`), без canvas.

### 3. Pilato — шрифт ✅

- Шрифт: **PP Neue Montreal** (Pangram Pangram) — Book 300 для всего, Medium 500 для акцентов; подписи —
  Arcon. Крупно и легко: H1 45/48, текст 17/32 (очень воздушный интерлиньяж), крупные цитаты 65/72,
  трекинг нулевой, капс только в мелком меню 13px.
- Кириллица: в их файлах **есть** (проверено в браузере сравнением ширин).
  Лицензия: **платная** — бесплатно только для личных проектов, для сайта нужна веб-лицензия Pangram Pangram.
  → для тестового берём бесплатный аналог.
- Бесплатные гротески с кириллицей (Google Fonts, лицензия OFL — можно в коммерции), проверены через API:
  **Inter Tight**, **Geist**, Commissioner, Geologica, Golos Text. Без кириллицы (отпадают): Albert Sans,
  Host Grotesk, Funnel Display, Instrument Sans, Hanken Grotesk.
**19.10: заголовки вернули на фирменный Manrope 400/600 (задание 5 требует фирменные шрифты), Geist и Geist Mono остались.**
- Берём (предложение): **Inter Tight 300/500** — заголовки и крупный текст (самый близкий к Neue Montreal
  характер: узковатый, ровный, лёгкий в тонком весе), **Geist** 400 — текст, **Geist Mono** — подписи и
  счётчик сцен. Это заменит Manrope / Onest / JetBrains Mono. Альтернатива — Commissioner (мягче, теплее).
  Финальный выбор — по образцам на странице «Библиотека».

### 4. Blunt Umbrellas — кнопки и скругления ✅

- Кнопка: высота ~43px, `padding: 10px 28px`, **`border-radius: 6px`**, обводка 1 физический пиксель
  (`0.57px` на ретине), текст 13px, обычный регистр, **трекинг 0,18em**, вес 400.
  Основная — заливка, второстепенная — только обводка.
- Ховер: «шторка» — заливка уезжает вправо, новая въезжает слева: два слоя `linear-gradient`,
  анимируется `background-size` 0,45s `cubic-bezier(.785,.135,.15,.86)`. Без теней и подпрыгиваний.
- Остальные скругления — почти нули (2px в плашках, картинки без скругления).
- Берём: кнопки 6px вместо таблеток 999px; карточки/плашки — 8–10px вместо 18–24px; бейджи — 4px;
  поле формы 6px. Трекинг 0,14–0,18em на тексте кнопок; ховер-шторка голубым `--portal` с тёмным текстом.

### 5. Overworld Audio /studio — цвета ✅

- Как сделано: холодный монохром без яркого акцента (CSS-переменные сайта):
  фон `--off-black #13151F`, текст `--off-white #E9ECEE`, второстепенный `#AAB9C7`, приглушённый `#6E8799`,
  тёмный `#4C5E6B`, поверхность `#1A1A1A`, линии `hsla(0,0%,91%,.1)`. Слева панель с градиентом от чёрного
  в глубокий синий (~`#2B4A68`, рисуется WebGL, цвет на глаз). Фото приглушённые и холодные.
- Совпадение с нами: их синий почти равен нашему `--lining #274A6E`, их фон — нашему `--night`.
  Отличие — у нас кремовый текст `--paper #F1ECE3`, у них холодный белый.
- Варианты на доске («Библиотека» → «Палитра — варианты»):
  - **А · Холодный**: `--night #13151F`, текст `#E9ECEE`, шкала `#AAB9C7 / #6E8799 / #4C5E6B`,
    градиент «ночь → `--lining`» за плашками; `--portal #7FD3FF` — единственный яркий цвет (курсор, прогресс,
    ховер, метки). `--paper` остаётся в знаке и карточке героя.
  - **Б · Холодный + крем — ВЫБРАНО** (18.10): как А, но главная кнопка и знак кремовые `--paper` — как на рекламных материалах (визитки, значок, кружка, баннер: тёмно-синий + крем).
    Токены: `--night #13151F`, `--text #E9ECEE`, `--text-soft #AAB9C7`, `--muted #6E8799`, `--paper #F1ECE3` (кнопка, знак), `--lining` — градиент фона, `--portal` — акцент.
  - Сейчас: кремовый текст на графите.
