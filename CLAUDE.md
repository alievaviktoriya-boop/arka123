# Сайт «АРКА 123»

Тестовое задание на вайбкодера: одностраничный сайт аренды зала «АРКА 123» (Минск, ул. Мстиславца, 10).
Статика на чистом HTML/CSS/JS, без сборки и npm. Язык контента и общения — русский.
Бриф, сроки и состояние работ — в `docs/plan.md`. Исходные наработки и материалы лежат вне проекта:
`C:\Users\tailo\Downloads\Тестовое`.

## Команды

- Локальный сервер: `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:8080 (умеет Range — без этого браузер не перематывает видео)
  (в Claude Desktop — превью `site` из `.claude/launch.json`)
- Node.js и Python не установлены — не предлагать решения, которые их требуют, без согласия владельца.
- ffmpeg установлен через winget (`Gyan.FFmpeg`): перекодировать видео, резать стоп-кадры.
  Стоп-кадр (показывается поверх видео, пока сцена стоит, — он чётче паузы ролика): из исходника
  `ffmpeg -ss <сек> -i "Тестовое/Генерации/видео-полное.mp4" -frames:v 1 -vf "scale=1920:-2:flags=lanczos,unsharp=5:5:0.7:5:5:0" -q:v 3 assets/img/stills/t-<сек>.jpg`;
  `t-5.04.jpg` — из оригинала `кадр-2-в-зале-у-стены-4.png`. Стоп-кадр поверх видео обязан совпадать с видео по лицу,
  иначе при подъезде лицо «перетекает» (полная ретушь лица в Gemini так и не подошла, см. docs/video.md).
  `t-0.jpg` (он же `place/promenade-evening.jpg`) — из `кадр-1-финал-5.png` (2752px) с исправленным контуром головы:
  от Gemini взято только кольцо (уши, скулы, шея), лицо исходное — `design/retouch/kadr-1-edges.png`, маска `mask-ring.png`

## Структура

Сайт устроен как в референсе заказчика (Porsche): фон всего сайта — видео с Аркадием на весь экран,
страница не прокручивается — шаг колеса / свайп / стрелка переключают **сцены**; блок сцены гаснет,
проигрывается переход, проявляется блок следующей сцены.

- `index.html` — прелоадер, `.stage` (фон, `data-video`), `main.scenes` из 11 `section.scene`: Встреча → Портал → Аркадий →
  О зале → 3D → Форматы → Галерея → Тарифы → Отзывы → Контакты → Футер. Атрибуты сцены: `data-t` (секунда видео, где пауза),
  `data-still` (стоп-кадр этой секунды), `data-bg` (фото поверх видео — для сцен после конца ролика), `data-side="right"`,
  `data-mx` (видимая часть кадра по X на телефоне, %), `data-mx-wide` (то же для окон уже 16:9 — на первом экране держит библиотеку в кадре), `data-dur` (длительность перехода), `data-play="a-b"` (вперёд играть только этот отрезок видео — кадры с Аркадием заменены стоп-кадрами), `data-dim`, `data-name`
- `assets/video/arkadiy.mp4` — ролик из Kling (10 с, 1280×716), перекодирован ffmpeg: без звука, ключевой кадр каждые 4 кадра,
  faststart. Исходник — `Тестовое/Генерации/видео-полное.mp4`. Для экранов до 720px — `arkadiy-m.mp4` (960px, crf 26, тот же шаг ключевых кадров), `data-video-mobile` Стоп-кадры — `assets/img/stills/t-<секунда>.jpg`
- `js/scenes.js` — движок сцен: фон (видео вперёд проигрывается, назад — растворение в стоп-кадр),
  переходы, ввод (колесо с защитой от инерции тачпада, свайп, клавиши, ссылки `#id`), счётчик `01 / 11`.
  Наружу: `window.arkaScenes.step(±1)`, `goTo(i)`; события `scene:enter` / `scene:leave` на секции
- `css/style.css` — токены, логотип/лоадер, шапка, фон, сцены и стеклянные плашки, карточки, адаптив
- `js/logo.js` — SVG-знак, тёмный прелоадер «портал Аркадия» (светящаяся арка, счётчик, раскрытие окна в первый кадр), блик на ховер; в начале выхода шлёт `arka:opening`, по окончании — `arka:loaded`
- `js/gallery.js` — лента фото на canvas; живёт, пока открыта её сцена
- `js/cursor.js` — след курсора голубым `--portal` поверх видео (canvas в `.stage`, только мышь, без reduced-motion)
- `js/main.js` — меню, ленивая загрузка 3D (по `scene:enter`), проброс клавиш из 3D-iframe, форма
- `room3d/index.html` — 3D-зал на three.js (самостоятельная страница, встраивается iframe-ом по мере прокрутки)
- `assets/img/` — `logo/` маски логотипа, `hall/` фото зала, `place/` общие планы (финал — вечерний променад), `stills/` стоп-кадры видео

## Правила

- Цвета — только токены из `:root` (палитра из карточки героя: graphite, cloak, lining, portal, paper).
  Сайт тёмный (под видео), автоматической смены темы нет.
- Содержимое сцены должно влезать в экран 1280×720; длиннее — плашка листается внутри (так задумано на телефоне).
- Не ловить фокус/колесо внутри сцены без выхода: из любой сцены должен работать переход (кнопка «↓», клавиши).
- Типографика: неразрывный пробел перед тире, после коротких слов (и, в, на…) и между числом и единицей —
  прогнать после правки текстов: `perl tools/nbsp.pl < index.html > tmp.html` и заменить (perl есть в Git Bash).
- Факты о зале везде одинаковые: 123 м², потолки 4,5 м, два арочных окна 4 × 3 м (как на фото заказчика),
  до 85 гостей в рядах / 36 за столами / 22 за общим столом (как в 3D-сцене).
- Mobile-first проверка: на 375px нет горизонтального скролла. Учитывать `prefers-reduced-motion`.
- Тяжёлое (3D, фото галереи) грузится только при приближении к экрану.
- Новые фото — уменьшать до 1600px по длинной стороне, JPEG ~80%.
- JS — ванильный, без библиотек (кроме three.js в 3D). Если нужна библиотека — сначала спросить.

## Как работать

1. Перед правкой прочитать затрагиваемые файлы; для крупных изменений сначала коротко описать план.
2. После правок вёрстки — проверить в браузерной панели на 375px и на десктопе, консоль без ошибок
   (или `/check-site`). Новые стили видны только после полной перезагрузки, переход по якорю их не подтягивает.
3. Коммитить логическими шагами с сообщением на русском.
