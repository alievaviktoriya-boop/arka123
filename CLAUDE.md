# Сайт «moyasreda»

Статический сайт на чистом HTML/CSS/JS. Без сборки, без npm, без фреймворков.
Язык контента — русский (`lang="ru"`). Общаться с владельцем проекта — по-русски.

## Команды

- Локальный сервер: `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:8080
  (в Claude Desktop — превью `site` из `.claude/launch.json`)
- Другой порт: `... -File serve.ps1 -Port 3000`
- Node.js и Python в системе не установлены — не предлагать решения, которые их требуют,
  без явного согласия владельца.

## Структура

- `index.html` — главная; новые страницы кладём рядом в корень (`about.html`) или в папку (`blog/index.html`)
- `404.html` — отдаётся сервером на неизвестные пути; ссылки в нём абсолютные (`/css/...`)
- `css/style.css` — единственная таблица стилей. Сверху токены (`:root`), ниже сброс → раскладка → компоненты
- `js/main.js` — клиентский JS, подключается с `defer`
- `assets/img/` — изображения, `assets/fonts/` — шрифты (создать при необходимости)

## Правила кода

- Цвета, отступы, шрифты — только через CSS-переменные из `:root`. Новый цвет = новый токен
  плюс его значение в блоке `prefers-color-scheme: dark`.
- Классы по BEM-подобной схеме: `.block`, `.block__element`, `.block--modifier`.
- Mobile-first: базовые стили для узкого экрана, `@media (min-width: …)` для широкого.
  Никакого горизонтального скролла на ширине 375px.
- Семантическая разметка: `header/nav/main/section/footer`, один `h1` на страницу,
  `alt` у всех `img`, видимый `:focus-visible`.
- JS — ванильный ES2020+, без библиотек. Если библиотека всё же нужна — сначала спросить.
- У изображений указывать `width`/`height` и `loading="lazy"` (кроме первого экрана).
- Отступ 2 пробела, LF, UTF-8 (см. `.editorconfig`).

## Как работать

1. Перед правкой прочитать затрагиваемые файлы; для крупных изменений сначала коротко описать план.
2. После изменения вёрстки — проверить в браузерной панели: открыть превью `site`,
   посмотреть на ширине 375px и на десктопе, проверить консоль на ошибки
   (или запустить `/check-site`).
3. Коммитить логическими шагами с понятным сообщением на русском.
